# Semester Long Project 2026 - Introduction to Coding

## About
Hosted by sheCodes at Cal Poly Pomona, SLP gives its members the opportunity to gain hands-on collaborative project experience. Each group is led by a mentor to build a unique coding project. At the end of the semester, the groups come together for sheCode's SLP Demo Day to showcase their project!

This year's Intro to Coding team practiced coding in Python and using Git/GitHub.
Each member worked on practice exercises and implemented simple Python programs.

## How to Run
Ensure you have Python installed.
1. Clone the repository, and navigate to the desired program in the terminal.
2. Type `python filename.py`, replacing filename with the corresponding program file name.
